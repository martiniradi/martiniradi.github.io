# Personal Academic Website

A clean, modern personal website built with pure HTML, CSS, and JavaScript. No frameworks, no dependencies, no build process required.

## Features

- Responsive design that works on all devices
- Dark mode support based on system preferences
- Fast loading with minimal overhead
- Easy to customize and maintain
- Includes sections for publications, awards, and teaching experience

## Quick Start

1. Clone this repository
2. Open `index.html` in your browser
3. That's it! No build process needed.

## Customization

### Update Content

Edit the data files in the `data/` directory:
- `data/publications.js` - Your research publications
- `data/awards.js` - Awards and honors
- `data/experience.js` - Teaching and work experience

### Change Styling

Edit `css/styles.css` to customize colors, fonts, spacing, and layout.

### Modify Icons

Add your custom SVG icons to `assets/icons/` and reference them in the data files.

## Deployment

This website can be deployed to any static hosting service:

- **GitHub Pages**: Enable Pages in repository settings, select main branch
- **Netlify**: Drag and drop the folder or connect your repository
- **Vercel**: Import your repository and deploy
- **Any static host**: Upload all files via FTP/SFTP

## Structure

```
├── index.html           # Main HTML file
├── css/
│   └── styles.css      # All styling
├── js/
│   └── main.js         # JavaScript functionality
├── data/               # Content data files
└── assets/             # Images, icons, documents
```
